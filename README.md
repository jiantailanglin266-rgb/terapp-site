# TERAPP 公式ブランドサイト

テラヘルツの可能性を、美容とコンディショニングへ。TERAPP のブランドサイト（静的HTML）です。

## 構成
- 静的HTML多ページ（フレームワーク不使用）
- 共通デザインシステム: `assets/terapp.css` / `assets/terapp.js`（ヘッダー・フッター・演出をJSで全ページ注入）
- データ分離: `data/products.js` / `data/journal.js`
- SEO: 各ページ固有の meta / OGP / JSON-LD、`sitemap.xml`、`robots.txt`

## ローカルプレビュー
```bash
python -m http.server 8820 --directory .
# http://127.0.0.1:8820/
```
